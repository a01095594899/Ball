# 대포 게임 프로젝트 - 기능 요구 사항 명세서

## 1. 프로젝트 개요

### 1.1 목적
물리 기반 대포 게임 개발을 통해 객체 지향 프로그래밍의 핵심 개념을 학습하고, 실전 게임 개발 경험을 습득한다.

### 1.2 범위
- 10개 장(Chapter)으로 구성된 단계별 학습 과정
- 최종 결과물: 완전한 대포 게임과 벽돌 깨기 게임
- 공통 게임 객체를 활용한 두 가지 게임 구현

---

## 2. 핵심 게임 객체

### 2.1 공 (Ball)
| 항목 | 요구 사항 |
|------|----------|
| **속성** | 중심 위치, 반지름, 색상 |
| **제약** | 반지름은 양수여야 함 |
| **오류 처리** | 유효하지 않은 값 입력 시 오류 발생 |

### 2.2 움직이는 공 (MovableBall)
| 항목 | 요구 사항 |
|------|----------|
| **속성** | 속도 벡터 (수평, 수직 방향) |
| **동작** | 시간에 따라 위치 이동 |
| **이동 공식** | 새 위치 = 현재 위치 + 속도 × 시간 |

### 2.3 경계 충돌 공 (BoundedBall)
| 항목 | 요구 사항 |
|------|----------|
| **기능** | 경계 충돌 감지 및 반사 |
| **반사 동작** | 벽 충돌 시 속도 방향 반전 |
| **경계 검사** | 상하좌우 4개 경계에 대해 검사 |

### 2.4 상자 (Box)
| 항목 | 요구 사항 |
|------|----------|
| **속성** | 위치, 너비, 높이, 색상 |
| **용도** | 경계, 장애물, 목표물로 활용 |

### 2.5 움직이는 상자 (MovableBox)
| 항목 | 요구 사항 |
|------|----------|
| **속성** | 속도 벡터 (수평, 수직 방향) |
| **동작** | 시간에 따라 위치 이동 |
| **용도** | 움직이는 장애물, 움직이는 목표물, 패들 |

### 2.6 경계 충돌 상자 (BoundedBox)
| 항목 | 요구 사항 |
|------|----------|
| **기능** | 경계 충돌 감지 및 반사 |
| **반사 동작** | 벽 충돌 시 속도 방향 반전 |
| **용도** | 자동 이동 장애물, 왕복 이동 목표물 |

## 7. 벽돌깨기 게임 시스템

|------|----------|

| **제어** | 키보드 또는 마우스로 조작 |

### 7.2 벽돌 (Brick)
| 항목 | 요구 사항 |
|------|----------|
| **속성** | 위치, 크기, 색상, 내구도, 점수 |
| **파괴** | 공과 충돌 시 내구도 감소 |
| **효과** | 파괴 시 시각 효과 및 점수 획득 |

### 7.3 벽돌 종류
| 타입 | 색상 | 내구도 | 점수 | 특징 |
|------|------|--------|------|------|
| 일반 | 파랑 | 1 | 10 | 기본 벽돌 |
| 강화 | 초록 | 2 | 20 | 2번 충돌 필요 |
| 강철 | 회색 | 3 | 30 | 3번 충돌 필요 |

| 타입 | 색상 | 효과 |
|------|------|------|

| 멀티볼 | 노랑 | 공 2개 추가 |
| 관통 | 보라 | 벽돌 관통 (5초) |

### 7.5 벽돌깨기 게임 규칙
| 항목 | 요구 사항 |
|------|----------|
| **시작** | 공이 패들 위에서 발사 대기 |
| **발사** | 스페이스바 또는 마우스 클릭으로 발사 |
| **생명 감소** | 공이 화면 하단으로 떨어지면 생명 -1 |
| **클리어** | 파괴 가능한 모든 벽돌 파괴 시 클리어 |
| **게임 오버** | 생명이 0이 되면 게임 오버 |

## 부록 A: 물리 공식 참조

### A.1 물리 공식
```
# 중력
F = m × g

# 포물선 운동
x = x₀ + vx × t
y = y₀ + vy × t + 0.5 × g × t²

# 반발 계수
v' = -v × e (0 ≤ e ≤ 1)

# 폭발 피해
피해비율 = 1 - (거리 / 폭발반경)
피해량 = 피해비율 × 기본피해

# 탄성 충돌 충격량
J = (1+e) × v_rel / (1/m₁ + 1/m₂)
```

### A.2 각도 계산
```
# 마우스 위치로 각도 계산
angle = atan2(mouseY - cannonY, mouseX - cannonX)

# 각도를 속도로 변환
vx = cos(angle) × power
vy = sin(angle) × power
```
